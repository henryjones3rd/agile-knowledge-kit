# About this project

Built by **Henry Jones III**, a delivery leader with 25+ years helping
engineering teams ship. The content comes from practices developed while
coaching distributed teams across three continents.

## What this project demonstrates

| Practice | Where to see it |
| --- | --- |
| Docs-as-code | Markdown in Git, pull request workflow, MkDocs |
| CI/CD for content | GitHub Actions: lint, validate, build, publish |
| Content quality automation | Link, freshness, front matter, and terminology checks in `tools/` |
| Prose linting | Vale with a project style and vocabulary |
| AI-ready knowledge | Generated `llms.txt` and `llms-full.txt` |
| Answer-accuracy evaluation | Retrieval eval set in `evals/questions.yml` |
| MCP-accessible source | A small MCP server in `mcp_server/` that serves these docs to AI agents |
| Standards as templates | [Reservation request template](reusable-templates/reservation-request.md) |
| Tribal knowledge to self-service | Every playbook and decision guide |

# WIP limits and swarming

Stop starting, start finishing. A **work in progress (WIP) limit** caps how many
items the team works on at once.

## Why the hockey stick happens

When each person owns their own items, everything is "in progress" until the
last two days. Then it all closes at once, or doesn't.

## Set a WIP limit

1. Count the people on the team.
2. Set the in-progress limit below that number. For six people, start at four.
3. When the column is full, nobody starts new work. They help finish existing work.

## Swarming

**Swarming** means several people work together on the top item until it is
done. It replaces "my tickets" with "our sprint goal."

- Pair on code and reviews.
- Test while development is still underway.
- Celebrate items finished, not items started.

## Measure it

Track how many items finish in the first half of the sprint. That number should
rise as the hockey stick flattens.
